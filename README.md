# タイムバケット サポート

やりたいことを年代で整理し、実現した体験を残すiPhoneアプリ「タイムバケット」のサポート窓口です。

- [使い方とよくある質問](https://okapiron.github.io/timebucket-support/)
- [プライバシーポリシー](https://okapiron.github.io/timebucket-support/privacy/)
- [お問い合わせ・不具合報告・ご要望](https://github.com/Okapiron/timebucket-support/issues/new/choose)

投稿にはGitHubアカウントが必要です。Issuesへの投稿は公開されます。生年月日、個人の写真・メモ、バックアップファイル、Apple Accountや認証情報は投稿しないでください。
